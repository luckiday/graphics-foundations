# Graphics Foundations

Notes, interactive demos and worked problems for learning the foundations of computer graphics: the math, the rendering pipeline, and the algorithms behind real-time and ray-traced images.

The material grew out of six quarters of discussion sections for UCLA's **CS 174A, Introduction to Computer Graphics** (2019–2021). It has been rewritten here as a self-contained, topic-by-topic resource. Every figure is an original drawing, every demo runs in the browser, and every worked number is checked by a script.

**[Open the live demos →](https://luckiday.github.io/graphics-foundations/demos/)**

---

## Running the demos

The demos work best in a desktop browser with WebGL 2 (current Chrome, Firefox, Safari or Edge). Use the [live version](https://luckiday.github.io/graphics-foundations/demos/), or run them locally:

```bash
git clone https://github.com/luckiday/graphics-foundations.git
cd graphics-foundations
node tools/serve.mjs          # then open http://localhost:8000/demos/
```

Demo 01 is plain WebGL, so you can see every call. Demos 02–07 are built on [TinyGraphics.js](https://github.com/intro-graphics/TinyGraphics.js), a small teaching library, loaded from its published copy. To develop against a local clone of the library, run `TINYGRAPHICS=../TinyGraphics.js node tools/serve.mjs`.

## Repository layout

```
notes/        the chapters
exercises/    practice problems with worked solutions
figures/      SVG figures, generated by tools/figures.py
demos/        interactive demos (one HTML file each) and small shared helpers in demos/lib/
tools/        local server and the checks below
```

## Checks

The notes are tested like code:

```bash
npm install                         # playwright-core, used only by the demo check
node tools/check-math.mjs           # recompute every worked number in notes/ and exercises/
node tools/check-links.mjs          # links, anchors, original-figures-only, no course logistics
node tools/check-demos.mjs          # load each demo in headless Chromium, press every control, screenshot
python3 tools/figures.py            # regenerate figures/ from code
```

`check-demos` needs a local Chromium with WebGL 2, and writes screenshots to `tools/shots/` for a person to look at.
